# FizzBuzzRules
This project provides a java-based solution for the FizzBuzz problem

**Version:** 925cf7f189d1e404cfd55df6e8398d831df0f45a

## Features
- Generates 'fizz' for multiples of 3
- Generates 'buzz' for multiples of 5
- Generates 'fizzbuzz' for multiples of 15
- Returns the number itself for other cases
- Throws InvalidRangeException in case initial and end range is not valid
